# difu

*dīfu* is your diff *shīfu*: a workspace for Codex and Claude Code coding agents
and guided GitHub pull request reviews.

| Directory | What it is |
| --- | --- |
| [`cli/`](cli/README.md) | The `difu` terminal app and its background agent service (Rust). |
| [`app/ios/`](app/ios/README.md) | The native iOS companion that controls a paired difu over Wi-Fi. |

Install the CLI with `brew install opencx-labs/tap/difu`, or see
[cli/README.md](cli/README.md) for building from source and full usage.
