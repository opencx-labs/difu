# Settings shortcut coverage

The production registry contains **189 action IDs across 93 contexts**. This table
maps every editable action to enabled tests that exercise its actual dispatch.
The registry itself records exact context membership; tests cover default keys,
saved replacements, removed aliases, reset/discard, editing ownership, effective
hints and relevant mouse targets. External provider/GitHub effects use explicit
fake transport boundaries; owned local Git/filesystem effects run for real.

See [verification](2026-10-22-settings-verification.md) for platform results and
[decisions](2026-10-22-settings-decisions.md) for modifier/ownership tradeoffs.
The runtime catalog is in `cli/src/shortcuts/catalog/`; test function names below
are searchable under `cli/src/`. Five provisional MCP slots and an unreachable
approval-text action were removed; future unknown stored IDs remain opaque.
